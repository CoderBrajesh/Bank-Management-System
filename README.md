# 🏦 Bank Management System — SecureBank


## 📌 Project Overview

SecureBank is a front-end banking application designed to demonstrate the basic functionality of an online banking system. It includes a login page, interactive dashboard, account management, transaction handling, and other banking-related features.

The application uses browser `localStorage` to store demo account information and transaction data.

## ✨ Features

- 🔐 **Login System** — Demo login page with password visibility toggle and remember-me functionality.
- 📊 **Dashboard** — View account balance, total deposits, withdrawals, and account summaries.
- 💰 **Deposit Money** — Simulate deposits and update the account balance.
- 💸 **Withdraw Money** — Simulate withdrawals from the available balance.
- 🔄 **Money Transfer** — Simulate transferring money to another beneficiary.
- 📋 **Transaction History** — View banking transaction records.
- 👤 **Account Details** — View account information and profile details.
- 💳 **Card Management** — View card details and manage card status.
- 👥 **Beneficiaries** — Manage saved beneficiaries.
- 📄 **Bank Statement** — Access account transaction statements.
- 🔔 **Notifications** — View banking-related notifications.
- ⚙️ **Settings** — Manage available application preferences.
- 📱 **Responsive Design** — Layouts designed for desktop, tablet, and mobile screens.
- 💾 **Local Storage** — Persist demo banking data in the browser.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layouts, responsive design, and visual effects.
- **JavaScript** — Application logic, form handling, and interactive features.
- **Browser localStorage** — Local persistence of demo account data.



## 💡 Learning Objectives

This project demonstrates practical front-end development concepts, including:

- Creating a multi-page web application.
- Designing responsive user interfaces with CSS.
- Handling forms and user interactions with JavaScript.
- Managing data using browser `localStorage`.
- Updating dashboard information dynamically.
- Organizing code into separate HTML, CSS, and JavaScript files.
- Implementing basic client-side login flow and page navigation.

## 🔮 Future Improvements

The project can be extended with the following features:

- Backend integration using Node.js and Express.
- Database integration using MySQL or MongoDB.
- Secure authentication and password hashing.
- Server-side transaction validation.
- Real-time account updates and transaction records.
- Secure APIs and role-based access control.
- Automated testing and deployment.

## ⚠️ Important Disclaimer

This is an **educational front-end demonstration project**, not a production-ready banking system. It does not connect to a real bank or process actual financial transactions. Data is stored locally in the browser, and the demo login is not secure authentication. Do not use real banking credentials, card information, or sensitive personal data.
